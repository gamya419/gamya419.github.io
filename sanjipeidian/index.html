三级配电箱配置要求

施工现场临时用电安全的核心规范，确保用电安全与工程质量的必备指南

查看详细标准

三级配电箱的核心定义

三级配电是指将电能从总配电箱分配到分配电箱，再由分配电箱供给开关箱，最后由开关箱控制用电设备的配电系统。

一级配电箱 (总配电箱)

设置在施工现场中心附近，距离用电负荷中心较近处。负责从变压器或总配电室引出电源，向二级分配电箱供电，并兼有总隔离开关、分路隔离开关、总断路器、分路断路器及漏电保护器。

  • 具有漏电总保护功能
  • 具备短路、过载保护
  • 作为施工现场的总电源控制点

二级配电箱 (分配电箱)

设置在用电负荷相对集中区域，负责向末级开关箱分配电能。它不直接控制用电设备，而是连接一级和三级配电箱。

  • 具有漏电分级保护功能
  • 控制范围较广
  • 通常安装在坚固的支架或专用电箱上

三级配电箱 (开关箱)

直接控制移动式或手持式用电设备，是配电系统的末级保护。必须做到“一机一闸一漏一箱”。

  • 必须具备漏电末级保护
  • 距离设备距离近，便于操作
  • 严禁重复供电

具体技术配置要求

1

“一机一闸一漏一箱”制度

每一台用电设备必须有自己专用的开关箱，严禁同一个开关箱直接控制2台及2台以上的用电设备（含插座）。开关箱内必须装设隔离开关、断路器、漏电保护器。

2

漏电保护器参数要求

总配电箱和开关箱中两级漏电保护器的额定漏电动作电流和额定漏电动作时间应合理配合，做到分级保护。开关箱中漏电保护器的额定漏电动作电流不应大于30mA，额定漏电动作时间不应大于0.1s。

3

电缆敷设与选型

电缆应采用架空或埋地敷设，严禁沿地面明敷，防止机械损伤和介质腐蚀。开关箱内电缆应采用橡胶护套铜芯电缆，或采用橡皮绝缘电缆。

4

配电箱体防护等级

配电箱的金属箱体、金属电器安装板以及电器正常不带电的金属底座、外壳等必须通过PE线端子板与PE线做电气连接，金属箱门与金属箱体必须采用编织软铜线做电气连接。开关箱箱体应防雨、防尘，防护等级不应低于IP44。

5

配电系统保护接地

施工现场临时用电系统必须采用TN-S接零保护系统（三相五线制）。PE线必须专用，严禁与N线混用。配电箱内应设置专用保护接地端子板。

安全验收与检查要点

✓
标识清晰

箱门上应有设备名称、编号、责任人及操作规程牌。

✓
锁闭管理

所有配电箱必须上锁，由专业电工专人负责开启和关闭。

✓
定期检测

漏电保护器应每月进行一次跳闸试验，确保灵敏有效。

✓
防雨防尘

箱体不得有严重锈蚀、凹陷或破损，箱体底部应有进线孔和出线孔。

✓
严禁带电移动

移动式开关箱在停止作业时必须断电上锁，严禁在通电状态下移动。

✓
进出线管理

进出线应排列整齐，不得有绞接现象，导线应压接牢固，不得有裸露带电部分。

常见问题解答 (FAQ)

三级配电箱和二级配电箱的区别是什么？

一级配电箱（总箱）负责整个工地的电源分配，具有总漏电保护；二级配电箱（分配箱）负责向各区域供电，具有分路保护；三级配电箱（开关箱）直接控制设备，是末级保护，必须严格做到“一机一闸一漏一箱”。

开关箱内的漏电保护器可以不装吗？

不可以。根据《施工现场临时用电安全技术规范》（JGJ 46-2005），开关箱内必须装设漏电保护器。对于潮湿、金属容器内等特殊环境，漏电保护器的额定漏电动作电流应更小（通常不大于15mA），动作时间不大于0.1s。

配电箱内可以使用铜丝代替熔断器吗？

严禁使用铜丝、铝丝代替熔断器或热元件。配电箱内的电气元件必须与配电箱的容量相匹配，严禁超负荷运行。若熔断器损坏，必须使用同规格的熔断器或断路器进行更换。

临时用电工程验收需要哪些资料？

需要验收的资料包括：临时用电施工组织设计审批表、电气设备试验检测记录、接地电阻测试记录、电工及特殊工种培训考核记录、安全操作规程等。验收合格后方可投入使用。
